# ID del Test: RC012  
# Título: crear comentario a un post ya creado

# Descripción  
Verificar que el endpoint no permite crear un comentario a un post con id invalido

# Precondiciones  
- Tener acceso a la URL pública de la API para realizar pruebas.  
- El endpoint debe estar activo y funcionando correctamente.  
- El id no debe estar asociado a ningun post
- El usuario tiene que estar autenticado y su token tiene que estar vigente

# Ambiente  
- URL: https://oauth.reddit.com/api/comment

# Pasos  
1. Abrir Postman.  
2. Seleccionar el método **POST**.  
3. Ingresar la URL: https://oauth.reddit.com/api/comment`  
4. Enviar el cuerpo con los campos id invalido y text.
5. Presionar el botón **Send** para enviar la solicitud.  
6. Verificar la respuesta recibida.

# Resultado esperado  
- Código de respuesta HTTP: **403, 404**  
- El estado de la respuesta (`response.status`) debe indicar error.  
- La respuesta debe contener el campo error.

# Prioridad  
Media (2)

# Categoría  
Funcional,Regresion
